# Haze-Busting Global Services — Website (v0.13 · Plum & Rose Gold)

Static website (HTML, CSS and JavaScript — no build step needed to view it).

**Colour theme:** Plum & Rose Gold — Plum with rose-gold accents, on white.

## How to view
- Live site: https://kiwigroupproject.github.io/hazebusting-website-v0-13/
- Or download / clone this repository and open `index.html` in a browser.
- Pages: Home, About Us, HR Services, Other Services (Recruitment · HR Certification Course), Contact Us.
- An internet connection is needed for web fonts, the smooth-scroll/animation libraries and the Contact map.

## Structure
```
index.html · about.html · hr-services.html · other-services.html · contact.html
css/style.css     styles
js/main.js        interactions and animation
assets/           logo, founder photo and images
tools/build.js    page generator (Node.js) — node tools/build.js
```
